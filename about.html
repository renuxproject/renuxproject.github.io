About the Project

Renux is a modern BSD operating system, designed to be easy to maintain and debug, with a focus on portability and performance. It is derived from the FreeBSD source tree and brings the classic NetBSD build.sh entry point to a Berkeley-heritage kernel and userland, so the whole tree builds from a single script on any Unix host.

Source Roadmap

The tree is organized so that every component lives where you would expect it. The kernel is under sys/, userland under bin/, sbin/, usr.bin/ and usr.sbin/, and libraries under lib/. Third-party code is cleanly separated in contrib/, gnu/ and crypto/.

DirectoryDescription
sysKernel sources.
bin, sbinSystem and user commands.
usr.bin, usr.sbinUser commands and system administration.
lib, libexecSystem libraries and daemons.
contrib, gnu, cryptoThird-party software.
standBoot loader sources.
releaseRelease and VM image building.
testsKyua test suite.

Design Goals

  • Maintainability — a source tree that is understandable and modifiable by everyone.
  • Portability — cross-builds on any Unix host: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • Performance — aggressive, well-tuned defaults for throughput and low latency.
