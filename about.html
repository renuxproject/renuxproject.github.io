About the Project

Renux is a modern BSD operating system, designed to be easy to maintain and debug, with a focus on portability and performance. It is derived from the FreeBSD source tree and built with the Renux Build System (renux), so the whole tree compiles from a single script on any Unix host — with few host dependencies: just a C compiler (clang) and a handful of standard utilities. Everything else is bootstrapped from the tree, no preinstalled FreeBSD host or toolchain required.

Design Goals

  • Maintainability — a source tree that is understandable and modifiable by everyone.
  • Portability — cross-builds on any Unix host: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • Performance — aggressive, well-tuned defaults for throughput and low latency.
  • Hackability — tunable and traceable at runtime (sysctl, kld, DTrace) and easy to rebuild from a single script.

Source Roadmap

The tree is organized so that every component lives where you would expect it:

  • sys/ — kernel sources (machine-independent code, with per-arch code under sys/arch/).
  • bin/, sbin/, usr.bin/, usr.sbin/ — user and system commands.
  • lib/, libexec/ — system libraries and daemons.
  • contrib/, gnu/, crypto/ — third-party software.
  • stand/ — boot loader sources.
  • release/ — release and VM image building.
  • tests/ — the Kyua test suite.

Community-Driven & Decentralized

Renux is a community project: driven by whoever shows up to build and improve it, and decentralized by design — in the community and in the system. There is no "official" versus "unofficial" Renux, and no single project, company or platform that owns it.

Anyone can take the source, host it anywhere (a self-hosted forge, a mirror, a tarball), and build their own Renux their own way. Forks and independent efforts are welcomed rather than treated as competition. The decentralization policy describes the principles, governance and infrastructure of the ecosystem.
