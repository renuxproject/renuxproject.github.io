Get the Source

The source tree is hosted on GitHub. No preinstalled FreeBSD host or toolchain is required — Renux will bootstrap everything it needs.

$ git clone https://github.com/renuxproject/src.git /usr/src/renux
$ cd /usr/src/renux

Build with build.sh

Renux brings the classic NetBSD build.sh entry point to a modern Berkeley-heritage system. The script is self-contained and portable, automatically provisioning any missing host tools into obj/host-shims.

# Build world (userland) and the kernel
$ ./build.sh build

# Build only the kernel (no buildworld needed)
$ ./build.sh kernel=GENERIC
$ ./build.sh kernel.gdb=GENERIC        # GDB-debuggable kernel
$ ./build.sh kernels                   # build all kernels

# Bootable images (kernel + loader, no userland)
$ ./build.sh bootimage                 # UEFI disk + BIOS ISO
$ ./build.sh iso                       # UEFI ISO + BIOS ISO
$ ./build.sh qemu                      # boot the UEFI image in QEMU
$ ./build.sh -L bios qemu              # boot the BIOS ISO in QEMU

# Other useful operations
$ ./build.sh world                     # buildworld only
$ ./build.sh distribution              # build distribution
$ ./build.sh release                   # build a release
$ ./build.sh update                    # git pull --ff-only

Options

$ ./build.sh -m amd64 -a amd64 kernel=GENERIC  # explicit target
$ ./build.sh -j 8                 build          # parallel make
$ ./build.sh -n kernel=GENERIC    # dry-run
$ ./build.sh -K                   iso            # kernel-only image
$ ./build.sh -I /out/dir          bootimage      # output directory
$ ./build.sh -D /dest             world          # set DESTDIR
$ ./build.sh -U                   world          # unprivileged (NO_ROOT)

System Requirements

  • A modern amd64 (x86-64-v2) machine for the default target.
  • Any Unix host to build: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • For the bootable images: UEFI firmware (GPT/FAT32 ESP) or BIOS (El Torito ISO).
