EXPERIMENTAL — AMD64 only.

Renux is under constant development and is not stable. Features presented here may not all be present yet, and the system currently only targets amd64 (x86-64). The RSL (Renux Subsystem for Linux) is planned for the future, and the installer is still in development. Do not use it on production or important machines.

Download Renux

Daily snapshots are built automatically from main and published as ready-to-install images. Pick the newest one — a single ISO that boots on both UEFI and BIOS and installs with renuxinstaller.

Renux 0.1-CURRENT snapshot-20260817-2147
renux-installer.iso.xz 531 MB amd64 (x86-64)
Download snapshot

Every daily build is also listed on the GitHub Releases page if you want an older snapshot, and the last stable release is snapshot-20260814-2052.

Get the Source

The source tree is hosted on GitHub. No preinstalled host or toolchain is required — Renux will bootstrap everything it needs.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux

Build with renux

Renux brings the Renux Build System (renux) to a modern Berkeley-heritage system. The script is self-contained and portable, automatically provisioning any missing host tools into obj/host-shims.

# Build world (userland) and the kernel
root # ./renux build
# Build only the kernel (no buildworld needed)
root # ./renux kernel=GENERIC
# Bootable images (kernel + loader, no userland)
root # ./renux bootimage
root # ./renux iso
root # ./renux qemu
# Other useful operations
root # ./renux world
root # ./renux distribution
root # ./renux release
root # ./renux update

Supported Architectures

Currently amd64 (x86-64) is the stable target. The other ports live under sys/arch/ and are experimental — they are not usable yet.

ArchitectureDirectoryStatus
amd64 (x86-64, baseline x86-64-v2)arch/amd64Stable

ARM (32-bit)arch/armExperimental
ARM64arch/arm64Experimental
RISC-Varch/riscvExperimental
PowerPCarch/powerpcExperimental

System Requirements

  • A modern amd64 (x86-64-v2) machine for the default target.
  • Any Unix host to build: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • For the bootable images: UEFI firmware (GPT/FAT32 ESP) or BIOS (El Torito ISO).
