EXPERIMENTAL — AMD64 only.

Renux is under constant development and is not stable. Features presented here may not all be present yet, and the system currently only targets amd64 (x86-64). The RSL (Renux Subsystem for Linux) is planned for the future, and the installer is still in development. Do not use it on production or important machines.

Get the Source

The source tree is hosted on GitHub. No preinstalled FreeBSD host or toolchain is required — Renux will bootstrap everything it needs.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux

Build with build.sh

Renux brings the classic NetBSD build.sh entry point to a modern Berkeley-heritage system. The script is self-contained and portable, automatically provisioning any missing host tools into obj/host-shims.

# Build world (userland) and the kernel
root # ./build.sh build
# Build only the kernel (no buildworld needed)
root # ./build.sh kernel=GENERIC
# Bootable images (kernel + loader, no userland)
root # ./build.sh bootimage
root # ./build.sh iso
root # ./build.sh qemu
# Other useful operations
root # ./build.sh world
root # ./build.sh distribution
root # ./build.sh release
root # ./build.sh update

Supported Architectures

Currently only amd64 (x86-64) is supported and bootable. The tree carries ports for other architectures that are being brought up — they are not usable yet.

System Requirements

  • A modern amd64 (x86-64-v2) machine for the default target.
  • Any Unix host to build: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • For the bootable images: UEFI firmware (GPT/FAT32 ESP) or BIOS (El Torito ISO).
