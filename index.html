Renux is a modern BSD operating system, derived from the FreeBSD source tree and designed to be easy to maintain and debug, with a focus on portability and performance. It brings the classic NetBSD build.sh entry point to a Berkeley-heritage kernel and userland, so the whole tree builds from a single script on any Unix host.

From a finely-tuned ULE-derived scheduler to a lock-free per-CPU memory allocator, Renux is engineered around aggressive defaults that favor throughput without giving up the clean, comprehensible structure that makes a BSD system a pleasure to work with. Learn more ›

Features

sched_renux

An ULE-derived scheduler, now the default, tuned for CPU-bound throughput with aggressive balancing and preemptive work stealing.

RENUX_MALLOC

A lock-free kern_malloc fork with deep per-CPU bucket caches, enabled by default in GENERIC.

Aggressive VFS

renux_vfs_cluster and renux_vfs_subr ship aggressive I/O clustering defaults for storage throughput.

Full preemption

FULL_PREEMPTION on by default in GENERIC cuts dispatch latency throughout the kernel.

NetBSD-style build.sh

One script for everything: ./build.sh build for world and kernel, plus iso, qemu and release targets.

Portable cross-build

Cross-builds from FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS, without any preinstalled toolchain.

Get Renux

Clone the source tree and build it yourself. No preinstalled host toolchain is required — Renux bootstraps everything it needs:

$ git clone https://github.com/renuxproject/src.git /usr/src/renux
$ cd /usr/src/renux
$ ./build.sh build        # world + kernel
$ ./build.sh iso          # UEFI + BIOS bootable media
$ ./build.sh qemu         # boot it in QEMU
