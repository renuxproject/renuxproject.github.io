Renux is a modern BSD operating system, derived from the FreeBSD source tree and designed to be easy to maintain and debug, with a focus on portability and performance. It brings the classic NetBSD build.sh entry point to a Berkeley-heritage kernel and userland, so the whole tree builds from a single script on any Unix host.

From a finely-tuned ULE-derived scheduler to a lock-free per-CPU memory allocator, Renux is engineered around aggressive defaults that favor throughput without giving up the clean, comprehensible structure that makes a BSD system a pleasure to work with.

About the Project

Renux is a source tree you can actually understand. The kernel lives under sys/, userland under bin/, sbin/, usr.bin/ and usr.sbin/, with libraries in lib/, and third-party code cleanly separated in contrib/, gnu/ and crypto/. Every component builds with the same cross toolchain, and the whole thing is orchestrated by a single, self-contained build script.

The project targets broad portability: the tree cross-builds from FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS, automatically provisioning any missing host tools and tolerating newer host compilers. The result is a system that is equally at home on a developer laptop, a server, or an embedded board.

Features

sched_renux

An ULE-derived scheduler with aggressive optimization, now the default. Tuned for CPU-bound throughput with more aggressive balancing, tighter latency and preemptive work stealing.

RENUX_MALLOC

A drop-in kern_malloc fork with lock-free statistics and deep per-CPU bucket caches. Enabled by default in the GENERIC kernel.

Aggressive VFS defaults

renux_vfs_cluster and renux_vfs_subr deliver aggressive I/O clustering defaults tuned for storage throughput out of the box.

Full preemption

FULL_PREEMPTION is enabled by default in GENERIC, reducing dispatch latency throughout the kernel.

NetBSD-style build.sh

One script to rule them all: ./build.sh build for world and kernel, plus iso, bootimage, qemu, release and more.

Portable cross-build

Self-contained and portable: runs on any Unix host, bootstraps bmake and infers the clang/lld cross toolchain automatically.

Get Renux

Clone the source tree and build it yourself. No preinstalled FreeBSD host or toolchain is required — Renux will bootstrap everything it needs.

$ git clone <repo> /usr/src/renux
$ cd /usr/src/renux

# Build world (userland) and the kernel
$ ./build.sh build

# Build only the kernel, no buildworld needed
$ ./build.sh kernel=GENERIC

# Bootable media (UEFI + BIOS), then boot it in QEMU
$ ./build.sh iso
$ ./build.sh qemu

System requirements

  • A modern amd64 (x86-64-v2) machine for the default target.
  • Any Unix host to build: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS.
  • For the bootable images: UEFI firmware (GPT/FAT32 ESP) or BIOS (El Torito ISO).

Community & Development

Renux is a hands-on project. The source is organized so that the whole tree is meant to be understandable and modifiable — every subsystem is open to inspection, and the test suite under tests/ is run via Kyua.

  • Mailing lists — development and users lists, following the classic BSD conventions.
  • Bug reporting — via the project's issue tracker and the automated CI under .github/ and .cirrus-ci/.
  • Code review — the tree ships .arcconfig and .arclint for the Phabricator-style workflow used by the upstream heritage.

Support

Before asking for help, check the documentation shipped with the tree and the UPDATING file for known issues. When in doubt, show the exact commands you ran and the output of ./build.sh show-params — it makes diagnosing build problems much faster.

  • ./build.sh -n kernel=GENERIC — dry-run, shows the commands.
  • ./build.sh list-arch — list supported architectures.
  • ./build.sh show-params — show current build parameters.
