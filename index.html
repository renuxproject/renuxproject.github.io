About

Renux is a modern BSD operating system, designed to be easy to maintain and debug, with a focus on portability and performance. The whole tree is meant to be understandable and modifiable, and it builds from a single portable script on any Unix host.

Read more ›

Features

sched_renux

An ULE-derived scheduler, now the default, tuned for CPU-bound throughput with aggressive balancing and preemptive work stealing.

RENUX_MALLOC

A lock-free kern_malloc fork with deep per-CPU bucket caches, enabled by default in GENERIC.

Aggressive VFS

renux_vfs_cluster and renux_vfs_subr ship aggressive I/O clustering defaults for storage throughput.

Full preemption

FULL_PREEMPTION on by default in GENERIC cuts dispatch latency throughout the kernel.

NetBSD-style build.sh

One script for everything: ./build.sh build for world and kernel, plus iso, qemu and release targets.

Portable cross-build

Cross-builds from FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS, without any preinstalled toolchain.

Get Renux

Clone the source tree and build it yourself:

$ git clone https://github.com/renuxproject/src.git /usr/src/renux
$ cd /usr/src/renux
$ ./build.sh build        # world + kernel
$ ./build.sh iso          # UEFI + BIOS bootable media
$ ./build.sh qemu         # boot it in QEMU
