A general-purpose operating system: easy to maintain, portable, and built with Zig.

Renux started from FreeBSD 15.1 and is becoming a system of its own. It keeps pulling FreeBSD's development in, a little at a time, so it stays current; its own code lives in its own files. Zig is its whole toolchain: the host needs nothing else, and the same source makes the same system on every machine.

Origin

Renux is Renan + Unix. Its creator, Renan Lucas Vieira Hilário, uses Linux and the BSDs, and saw how many toolchains and dependencies it takes to build them. Zig, his language of choice, compiles C, C++ and Zig for any machine, and it is a single binary. So the question came: what if an operating system were easy to maintain, portable, and built on many systems at the cost of Zig alone? Renux is the answer, and it is meant to be a technology anyone can take up.

Install Zig. Build the whole system.

Build

$ git clone --depth 1 https://github.com/renuxproject/renux.git
$ cd renux
$ zig build

On any host, with Zig 0.17. Renux is experimental: what builds and what comes next is in the README.
