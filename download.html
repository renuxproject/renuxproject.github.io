Renux Nightly build Experimental

Snapshots of Renux 0.1-CURRENT “Aurora”, built by GitHub Actions from the latest source. They are for testing: things change, and can break, from one build to the next.

Snapshots on GitHub All builds

The installer ISO boots into the Renux installer, which sets up the disk and the network and installs the system. The disk image is a ready system. Check and unpack what you download:

$ sha256sum -c SHA256
$ unxz renux-0.1-CURRENT-amd64-*-installer.iso.xz

Renux 0.1 “Aurora” In development

The first release of Renux. Aurora is in development, in 0.1-CURRENT, and there is nothing to download yet. Until it comes out, the nightly builds are its preview.
