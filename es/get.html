EXPERIMENTAL — solo AMD64.

Renux está en constante desarrollo y no es estable. Las características presentadas aquí pueden no estar todas presentes todavía, y el sistema actualmente solo apunta a amd64 (x86-64). El RSL (Renux Subsystem for Linux) está planificado para el futuro, y el instalador aún está en desarrollo. No lo use en máquinas de producción o importantes.

Descargar Renux

Los snapshots diarios se generan automáticamente desde main y se publican como imágenes listas para instalar. Descarga el más reciente — una sola ISO que arranca en UEFI y BIOS e instala con renuxinstaller.

Renux 0.1-CURRENT snapshot-20260817-2147
renux-installer.iso.xz 531 MB amd64 (x86-64)
Descargar snapshot

Todos los builds diarios también están listados en la página de Releases de GitHub si quieres un snapshot más antiguo, y la última release estable es snapshot-20260814-2052.

Obtener el Código Fuente

El árbol de fuentes está alojado en GitHub. No se requiere un host ni una cadena de herramientas preinstalada — Renux prepara todo lo que necesita.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux

Compilar con renux

Renux trae el Renux Build System (renux) a un sistema de herencia Berkeley. El script es autosuficiente y portable, y prepara automáticamente cualquier herramienta de host ausente en obj/host-shims.

# Compilar world (userland) y el kernel
root # ./renux build
# Compilar solo el kernel (sin buildworld)
root # ./renux kernel=GENERIC
# Imágenes de arranque (kernel + loader, sin userland)
root # ./renux bootimage
root # ./renux iso
root # ./renux qemu
# Otras operaciones útiles
root # ./renux world
root # ./renux distribution
root # ./renux release
root # ./renux update

Arquitecturas Soportadas

Actualmente amd64 (x86-64) es el objetivo estable. Los demás ports viven en sys/arch/ y son experimentales — todavía no son utilizables.

Requisitos del Sistema

  • Una máquina amd64 moderna (x86-64-v2) para el destino predeterminado.
  • Cualquier host Unix para compilar: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly o macOS.
  • Para las imágenes de arranque: firmware UEFI (GPT/ESP FAT32) o BIOS (ISO El Torito).
