EXPERIMENTAL — solo AMD64.

Renux está en constante desarrollo y no es estable. Las características presentadas aquí pueden no estar todas presentes todavía, y el sistema actualmente solo apunta a amd64 (x86-64). El RSL (Renux Subsystem for Linux) está planificado para el futuro, y el instalador aún está en desarrollo. No lo use en máquinas de producción o importantes.

Obtener el Código Fuente

El árbol de fuentes está alojado en GitHub. No se requiere un host FreeBSD ni una cadena de herramientas preinstalada — Renux prepara todo lo que necesita.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux

Compilar con build.sh

Renux trae el clásico punto de entrada build.sh de NetBSD a un sistema de herencia Berkeley. El script es autosuficiente y portable, y prepara automáticamente cualquier herramienta de host ausente en obj/host-shims.

# Compilar world (userland) y el kernel
root # ./build.sh build
# Compilar solo el kernel (sin buildworld)
root # ./build.sh kernel=GENERIC
# Imágenes de arranque (kernel + loader, sin userland)
root # ./build.sh bootimage
root # ./build.sh iso
root # ./build.sh qemu
# Otras operaciones útiles
root # ./build.sh world
root # ./build.sh distribution
root # ./build.sh release
root # ./build.sh update

Arquitecturas Soportadas

Actualmente solo amd64 (x86-64) es compatible y arrancable. El árbol incluye ports para otras arquitecturas que se están preparando — todavía no son utilizables.

Requisitos del Sistema

  • Una máquina amd64 moderna (x86-64-v2) para el destino predeterminado.
  • Cualquier host Unix para compilar: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly o macOS.
  • Para las imágenes de arranque: firmware UEFI (GPT/ESP FAT32) o BIOS (ISO El Torito).
