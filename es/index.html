Un sistema operativo de propósito general, fácil de mantener, portable y compilable con Zig.

Renux empezó en FreeBSD 15.1 y se está convirtiendo en un sistema propio. Sigue incorporando el desarrollo de FreeBSD, poco a poco, para mantenerse actualizado; el código de Renux vive en sus propios archivos. Zig es toda su toolchain: la máquina no necesita nada más, y el mismo código fuente produce el mismo sistema en cualquier computadora.

Origen

Renux es Renan + Unix. Su creador, Renan Lucas Vieira Hilário, usa Linux y los BSD y vio cuántas toolchains y dependencias hacen falta para construirlos. Zig, su lenguaje preferido, compila C, C++ y Zig para cualquier máquina, y es un solo binario. De ahí surgió la pregunta: ¿y si un sistema operativo fuera fácil de mantener, portable y se compilara en muchos sistemas con solo Zig? Renux es la respuesta, y la idea es que sea una tecnología que cualquiera pueda adoptar.

Instala Zig. Compila el sistema entero.

Compilar

$ git clone --depth 1 https://github.com/renuxproject/renux.git
$ cd renux
$ zig build

En cualquier sistema, con Zig 0.17. Renux es experimental: lo que ya compila y lo que viene después está en el README.
