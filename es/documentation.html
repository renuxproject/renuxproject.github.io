Compilar con el Renux Build System

El Renux Build System (la utilidad renux, el ./renux en la parte superior del árbol) dirige toda la compilación desde un único script, al estilo NetBSD. Funciona en cualquier host Unix — FreeBSD, Linux, NetBSD, OpenBSD, DragonFly o macOS — con pocas dependencias del host: solo un compilador de C (clang), algunas utilidades estándar y, para imágenes, xorriso/makefs. El resto lo prepara el propio árbol.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux
root # ./renux build
root # ./renux worldiso

Operaciones comunes: ./renux kernel=GENERIC (solo el kernel), ./renux iso (imágenes de arranque), ./renux qemu (arranque en QEMU), ./renux clean, ./renux update. Vea ./renux --help para la lista completa.
