⚠️
EXPERIMENTAL — somente AMD64.

O Renux está em constante desenvolvimento e não é estável. Os recursos apresentados aqui podem ainda não estar todos presentes, e o sistema atualmente suporta apenas amd64 (x86-64). O RSL (Renux Subsystem for Linux) é planejado para o futuro, e o instalador ainda está em desenvolvimento. Não use em máquinas de produção ou importantes.

Obter o Código-Fonte

A árvore de fontes está hospedada no GitHub. Não é necessário um host FreeBSD ou uma cadeia de ferramentas pré-instalada — o Renux prepara tudo o que precisa.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux

Compilar com renux

O Renux traz o Renux Build System (renux) para um sistema de herança Berkeley. O script é autossuficiente e portável, preparando automaticamente qualquer ferramenta de host ausente em obj/host-shims.

# Compilar world (userland) e o kernel
root # ./renux build
# Compilar somente o kernel (sem buildworld)
root # ./renux kernel=GENERIC
# Imagens inicializáveis (kernel + loader, sem userland)
root # ./renux bootimage
root # ./renux iso
root # ./renux qemu
# Outras operações úteis
root # ./renux world
root # ./renux distribution
root # ./renux release
root # ./renux update

Arquiteturas Suportadas

Atualmente amd64 (x86-64) é o alvo estável. Os demais ports vivem em sys/arch/ e são experimentais — ainda não utilizáveis.

ArquiteturaDiretórioStatus
amd64 (x86-64, base x86-64-v2)arch/amd64Estável
i386arch/i386Experimental
ARM (32 bits)arch/armExperimental
ARM64arch/arm64Experimental
RISC-Varch/riscvExperimental
PowerPCarch/powerpcExperimental

Requisitos do Sistema

  • Uma máquina amd64 moderna (x86-64-v2) para o alvo padrão.
  • Qualquer host Unix para compilar: FreeBSD, Linux, NetBSD, OpenBSD, DragonFly ou macOS.
  • Para as imagens inicializáveis: firmware UEFI (GPT/ESP FAT32) ou BIOS (ISO El Torito).
