Um sistema operacional de propósito geral, fácil de manter, portátil e compilável com Zig.

O Renux começou no FreeBSD 15.1 e está se tornando um sistema próprio. Ele continua trazendo o desenvolvimento do FreeBSD, aos poucos, para se manter atualizado; o código do Renux fica em arquivos próprios. O Zig é toda a sua toolchain: a máquina não precisa de mais nada, e o mesmo código-fonte gera o mesmo sistema em qualquer computador.

Origem

Renux é Renan + Unix. O criador, Renan Lucas Vieira Hilário, usa Linux e BSDs e percebeu quantas toolchains e dependências são precisas para construí-los. O Zig, a linguagem preferida dele, compila C, C++ e Zig para qualquer máquina, e é um binário só. Daí veio a pergunta: e se um sistema operacional fosse fácil de manter, portátil e compilasse em vários sistemas custando só o Zig? O Renux é a resposta, e a ideia é que ele seja uma tecnologia que qualquer um possa adotar.

Instale o Zig. Compile o sistema inteiro.

Compilar

$ git clone --depth 1 https://github.com/renuxproject/renux.git
$ cd renux
$ zig build

Em qualquer sistema, com o Zig 0.17. O Renux é experimental: o que já compila e o que vem a seguir está no README.
