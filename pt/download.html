Renux Nightly build Experimental

O Renux em desenvolvimento, compilado pelo GitHub Actions a partir do código mais recente, todo dia às 18:00 no horário de Brasília (21:00 UTC). Uma nightly build não tem versão: cada uma leva o dia e o commit de que saiu. São para testes: as coisas mudam, e podem quebrar, de uma build para a outra.

Renux 0.1.1 “Aurora” Experimental

O Renux 0.1.1 “Aurora”, a primeira atualização da 0.1, saiu, compilado com o Zig 0.17.1. Ele traz a memstick do instalador para um USB ou um disco externo. É experimental: leia as notas da versão antes de instalar.

Instalar

Grave a ISO do instalador num DVD, ou a imagem memstick num USB ou num disco externo com dd (isso apaga o destino), boote a máquina em modo UEFI e escolha Automático (UFS) ou Automático (ZFS). O Renux não inicia por BIOS (CSM, Legacy).

{% include terminal.html commands="write_memstick" %}
