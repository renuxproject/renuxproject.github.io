Compilar com o Renux Build System

O Renux Build System (a utilidade renux, o ./renux no topo da árvore) conduz todo o build a partir de um único script, no estilo NetBSD. Funciona em qualquer host Unix — FreeBSD, Linux, NetBSD, OpenBSD, DragonFly ou macOS — com poucas dependências de host: apenas um compilador C (clang), alguns utilitários padrão e, para imagens, xorriso/makefs. Todo o resto é preparado pela própria árvore.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux
root # ./renux build
root # ./renux worldiso

Operações comuns: ./renux kernel=GENERIC (só o kernel), ./renux iso (imagens inicializáveis), ./renux qemu (boot no QEMU), ./renux clean, ./renux update. Veja ./renux --help para a lista completa.
