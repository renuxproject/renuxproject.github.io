Community & Development

Renux is a hands-on project. The source is organized so that the whole tree is meant to be understandable and modifiable — every subsystem is open to inspection, and the test suite under tests/ is run via Kyua.

Get Involved

  • Build it — ./build.sh build gets you a running system.
  • Boot it — ./build.sh qemu runs the bootable image in QEMU.
  • Test it — run the Kyua suite under tests/.
  • Report issues — use the GitHub issue tracker.
  • Review code — the tree ships .arcconfig and .arclint for the Phabricator-style workflow used by the upstream heritage.

Channels

  • Mailing lists — development and users lists, following classic BSD conventions.
  • Issue tracker — bugs and feature requests on GitHub.
  • Continuous integration — automated builds under .github/ and .cirrus-ci/.
