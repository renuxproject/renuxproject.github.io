Renux 0.1.2 “Aurora” Experimental

Renux 0.1.2 “Aurora”, the second update of Renux 0.1, is out, built with Zig 0.17.1. Its installer no longer erases a disk it cannot install on, and it is for UEFI only. It is experimental: do not install it on a machine that holds data you need. It is amd64 and UEFI only.

Download→ Source

What is new in 0.1.2

  • The installer no longer destroys a disk it cannot install on. In 0.1.1, Auto (ZFS) prepared the disk to boot by BIOS too, with boot code Renux does not have (/boot/pmbr, /boot/gptzfsboot): it erased the disk's partitions and then stopped with an error, leaving neither the old system nor Renux. The installer now makes the disk for UEFI only.
  • Renux boots by UEFI only. When the installer was started by BIOS (CSM, Legacy), it says so and stops before it touches the disk.
  • The workarounds for booting GPT disks by BIOS on some Lenovo, HP, Intel and Acer machines are gone.

What is in it

  • The kernel, the EFI loader and the whole userland are built by zig build from the Renux source tree, with Zig 0.17.1 as the compiler.
  • Renux is based on FreeBSD 15.1 and follows FreeBSD's development.
  • 854 kernel modules are installed in /boot/modules, including ZFS and the drivers FreeBSD ships as modules.
  • The installer offers Auto (UFS) and Auto (ZFS). ZFS includes the kernel module, zpool/zfs and the loader support.
  • The release has an installer ISO for a DVD and an installer memstick for a USB stick or an external disk: a GPT disk with an EFI system partition and a UFS root, written with dd.
  • The installer speaks English, Spanish and Portuguese. It sets up the network and can install the package manager (pkg) from the Internet.
  • The console and the login: an underline cursor, full-screen programs, and a welcome from Renux.

Known limitations

  • amd64 and UEFI only: Renux does not boot by BIOS (CSM, Legacy).
  • The ZFS menu configures the pool, datasets and optional encryption; advanced pool layouts are manual.
  • In Spanish and Portuguese, the names of keymaps and of most time zones are still in English.
  • The system's compiler, Zig 0.17.1, is ziglang.org's build for FreeBSD; it is not yet built from the Renux tree.

Install

Write the installer ISO to a DVD, or the memstick image to a USB stick or an external disk with dd (it erases the target). Then boot the machine in UEFI mode and choose Auto (UFS) or Auto (ZFS); the installer sets up the disk and the network and installs the system. Do not install it on the disk you booted from.
