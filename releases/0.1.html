Renux 0.1 “Aurora” Experimental

The first release of Renux, 0.1 “Aurora”, is out. It is experimental: do not install it on a machine that holds data you need. It is amd64 and UEFI only.

Download→ Source

What is in it

  • The kernel, the EFI loader and the whole userland are built by zig build from the Renux source tree, with Zig 0.17 as the compiler.
  • Renux is based on FreeBSD 15.1 and follows FreeBSD's development.
  • 854 kernel modules are installed in /boot/modules, including ZFS and the drivers FreeBSD ships as modules.
  • The installer offers Auto (UFS) and Auto (ZFS). ZFS includes the kernel module, zpool/zfs and the loader support.
  • The installer speaks English, Spanish and Portuguese. It sets up the network and can install the package manager (pkg) from the Internet.
  • The console and the login, as in the nightlies: an underline cursor, full-screen programs, and a welcome from Renux.

Known limitations

  • amd64 and UEFI only: Renux does not boot by BIOS (CSM, Legacy).
  • The ZFS menu configures the pool, datasets and optional encryption; advanced pool layouts are manual.
  • In Spanish and Portuguese, the names of keymaps and of most time zones are still in English.
  • The system's compiler, Zig 0.17, is ziglang.org's build for FreeBSD; it is not yet built from the Renux tree.

Install

Write the installer ISO to a USB drive, boot the machine in UEFI mode, and choose Auto (UFS) or Auto (ZFS). The installer sets up the disk and the network and installs the system.
