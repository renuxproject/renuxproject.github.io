News

Renux source now on GitHub

2026-08-11

The complete Renux source tree is now mirrored at github.com/renuxproject/src, with a live commits feed on this site.

Project website launched

2026-08-11

The Renux project website is now live, with automatic light/dark theming, a news feed, and live development commits.

amd64 baseline raised to x86-64-v2

2026-08-11

The amd64 build now defaults to the x86-64-v2 baseline, enabling compiler optimizations that assume the modern CPU features most systems provide today.

sched_renux becomes the default scheduler

2026-08-11

The ULE-derived sched_renux scheduler, with aggressive optimization, balancing and preemptive work stealing, is now the default in GENERIC.

RENUX_MALLOC enabled by default in GENERIC

2026-08-11

The lock-free kern_malloc fork with deep per-CPU bucket caches is now enabled by default in the GENERIC kernel.

FULL_PREEMPTION on by default

2026-08-11

Full kernel preemption is enabled by default, reducing dispatch latency throughout the kernel.

Aggressive VFS defaults land in GENERIC

2026-08-11

renux_vfs_cluster and renux_vfs_subr deliver aggressive I/O clustering defaults tuned for storage throughput.
