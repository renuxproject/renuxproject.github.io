Features

sched_renux

An ULE-derived scheduler with aggressive optimization, now the default. Tuned for CPU-bound throughput with more aggressive balancing, tighter latency and preemptive work stealing.

RENUX_MALLOC

A drop-in kern_malloc fork with lock-free statistics and deep per-CPU bucket caches. Enabled by default in the GENERIC kernel.

Aggressive VFS defaults

renux_vfs_cluster and renux_vfs_subr deliver aggressive I/O clustering defaults tuned for storage throughput out of the box.

Full preemption

FULL_PREEMPTION is enabled by default in GENERIC, reducing dispatch latency throughout the kernel.

NetBSD-style build.sh

One script to rule them all: ./build.sh build for world and kernel, plus iso, bootimage, qemu, release and more.

Portable cross-build

Self-contained and portable: runs on any Unix host, bootstraps bmake and infers the clang/lld cross toolchain automatically.

Bootable Images

The iso and bootimage operations build the EFI loader from stand/ with the same cross toolchain and produce a kernel-only boot medium: EFI/BOOT/BOOTX64.EFI plus /boot/kernel/kernel on a FAT32 ESP, wrapped in a GPT disk (renux.img) or an El Torito ISO (renux.iso). These boot straight into the kernel; a full system requires world/ distribution.

Host Compatibility

The build script tolerates a host compiler newer than the one officially supported (kernel builds go out with -Werror disabled for portability) and treats Renux as a native FreeBSD host. Supported build hosts:

  • FreeBSD
  • Linux
  • NetBSD
  • OpenBSD
  • DragonFly BSD
  • macOS
