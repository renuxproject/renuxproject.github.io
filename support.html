Support

Before asking for help, check the documentation shipped with the tree and the UPDATING file for known issues. When in doubt, show the exact commands you ran and the output of ./build.sh show-params — it makes diagnosing build problems much faster.

Diagnostic Commands

# Dry-run: show the commands a target would run
$ ./build.sh -n kernel=GENERIC

# List supported architectures
$ ./build.sh list-arch

# Show current build parameters
$ ./build.sh show-params

Reporting Bugs

  1. Search the issue tracker for an existing report.
  2. Include the exact commands you ran and their output.
  3. Include ./build.sh show-params output and kernel configuration.
  4. For build problems, note your host OS and compiler version.

Security Information

Security advisories follow the classic BSD model and will be published on the news page as they are released.
