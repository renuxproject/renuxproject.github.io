Building with the Renux Build System

The Renux Build System (renux, the ./renux utility at the top of the tree) drives the whole build from a single script, the NetBSD-style way. It works on any Unix host — FreeBSD, Linux, NetBSD, OpenBSD, DragonFly or macOS — with few host dependencies: just a C compiler (clang), a few standard utilities, and for images xorriso/makefs. Everything else is bootstrapped from the tree.

user $ git clone https://github.com/renuxproject/src.git /usr/src/renux
user $ cd /usr/src/renux
root # ./renux build
root # ./renux worldiso

Common operations: ./renux kernel=GENERIC (kernel only), ./renux iso (bootable images), ./renux qemu (boot in QEMU), ./renux clean, ./renux update. See ./renux --help for the full list.
